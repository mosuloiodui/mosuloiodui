## 🚀 Featured projects

### 🧠 [FedAF-P: Federated Unlearning for Intrusion Detection](https://github.com/mosuloiodui/FU)
*INPT, engineering project · 2025–2026*
A federated learning system (FedAvg) with 1 server and 3 Linux VMs communicating over **MQTT**, classifying 10 attack classes of UNSW-NB15. **FedAF-P** removes one class from the global model without full retraining, using 3 layers: targeted gradient ascent, cosine penalty, and orthogonal projection, plus EWC distillation.
➡️ The forgotten class drops to **F1 = 0.000 on all 3 clients** in under 10 rounds, while macro F1 on the retained classes moves by **at most −0.018**.
`PyTorch` · `scikit-learn` · `FedAvg / FedProx` · `MQTT`

### 🛡️ [Carlini & Wagner Attack on an IDS](https://github.com/mosuloiodui/ROBUST-IDS)
*Constrained optimisation & robustness · 2026*
A C&W L2 attack on an intrusion-detection MLP (UNSW-NB15, baseline accuracy 85.2%, recall 97.7%). The threat model is realistic: only 3 traffic features can be modified (`dur`, `sbytes`, `dbytes`). The defence is an **Isolation Forest** trained on normal traffic, and an adaptive attack (L2 + c·f_CW + λ·IF) uses a differentiable surrogate.
➡️ **98%+** of detected attacks are turned into false negatives. The Isolation Forest catches **91.6%** of them (8.4% bypass).
`PyTorch` · `Adversarial ML` · `Isolation Forest`
